# Bank Loan Analysis | Power BI

## Project Overview
This project analyzes bank loan data to understand lending activity, repayment performance, borrower characteristics, and loan quality. An interactive Power BI dashboard presents key metrics to support data-driven decision-making.

## Business Objectives
- Monitor total loan applications and monthly trends.
- Analyze the total amount funded and amount received.
- Track average interest rates and debt-to-income (DTI) ratios.
- Compare good loans with bad loans.
- Explore loan performance by state, loan term, employee length, loan purpose, and home ownership.
- Provide a detailed view of individual loan records.

## Dashboard Pages
### 1. Summary
Presents key loan performance indicators, including loan applications, funded amounts, amounts received, interest rates, DTI, and good versus bad loan metrics.

### 2. Overview
Explores lending trends and borrower characteristics using visualizations such as monthly trends, state-level analysis, loan terms, employee length, loan purpose, and home ownership.

### 3. Details
Provides a detailed view of loan-level information to support further analysis.

## Tools Used
- **Power BI** — dashboard development and data visualization
- **PostgreSQL** — used during project analysis

The dashboard brings key lending metrics and borrower information together in one report, helping users explore loan activity and assess loan performance.
